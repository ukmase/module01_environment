# Readme
**Название:** module01_environment.

**Цель:** Проба пера в работе с Github-репозиториями; дополнительно - демонстрация последствий неправильного порядка команд и ячеек с кодом в .ipynb, а также основ работы с файлами.

**Состав файлов:**

* **Директория module01_environment:**

  README.md **(Readme)**

* **Директория module01_environment/notebooks:**
  
  lr01_runtime_order_Украинский.ipynb **(Notebook)**
* **Директория module01_environment/data:**
  
    sample_text.txt **(Текстовый файл)**
  
    mini_corpus.tsv **(Файл .tsv)**
* **Директория module01_environment/docs:**
  
    version_log.md **(История версий)**

**Как открыть:** Скачать Notebook и запустить в любой подходящей программе (проверено в браузерном Google Colab); скачать файл .tsv и загрузить его в сессионное хранилище; нажать "Выполнить все".

**Проверка:** Если ни одна ячейка кода не выдаёт ошибок, то всё работает как надо.

**Ограничения:** Последняя ячейка кода (посвящённая работе с файлами) может выдать ошибку "FileNotFoundError: [Errno 2] No such file or directory: 'mini_corpus.tsv'". В этом случае следует загрузить в сессионное хранилище файл .tsv.
